# 武鸣同路

面向 **武鸣民族高中 ↔ 广西各城市** 的家长自驾互助微信小程序。家长自行发布空位或搭车需求，双方确认接送；没有统一派车角色。

当前为 **第一版开发预览（MVP）**：原生微信小程序 + 本地演示适配器 + 微信云开发云函数。默认使用本地演示数据，**尚未连接真实云环境或正式上线**。

## 立即体验

1. 使用微信开发者工具，导入本仓库根目录（包含 `project.config.json` 的目录）。
2. 使用测试号 / 游客模式；如工具要求 AppID，填入你自己的小程序 AppID。
3. 保持 `miniprogram/config.js` 中 `mode: 'demo'`，点击编译。默认无需后端、无需安装 npm 依赖。
4. 从“找拼车”查看示例行程；从“我的”切换三位演示家长，模拟双方操作。

界面暂定名“武鸣同路”。学校名称和示例集合点均可调整。示例电话、车牌、集合点不用于真实接送；演示模式阻止拨号。

## 已实现的业务

- 发布驾车行程或单个孩子的搭车需求；双向路线、区域、时间、途经点、座位、集合点、车辆信息。
- 按方向、区域、日期、费用筛选，收藏家长的行程优先展示。
- 为孩子申请搭乘；车主接受 / 拒绝；车主可针对需求发邀请，由搭乘家长接受。
- 确认时占座、取消释放座位；同一学生前后 4 小时内不能重复确认其他行程。
- 记录学生知晓方式；未告知不能记录上车；按上车 → 到达 → 交接顺序推进。
- 联系电话和精确位置仅向相关已确认家长展示；未确认申请不展示对方手机号。
- 接送异常及处理记录；复制接送确认单、点名名单，可粘贴到文档后打印。
- 免费、每位学生固定费用、共同路段按实际公里 AA；账单金额确认与双方线下结清记录。
- 同一账号多个孩子、车辆与备用联系人；常用路线复用、收藏、屏蔽、举报记录。

## 建议演示路线

1. 默认身份为“林同学家长”。首页打开“南宁 · 安吉 / 公里 AA”，申请搭乘。
2. “我的”切换为“陈同学家长”，在“我的行程 → 我开车”接受申请。
3. 切回“林同学家长”，在该行程填写“确认已告知学生”的方式，复制接送确认单。
4. 切回“陈同学家长”，依次记录已上车、已到达、交接情况；填写实际公里与过路费并生成账单。
5. 切回“林同学家长”确认金额、记录线下付款；开车家长再记录线下收款。
6. 免费和固定费用行程可按相同步骤演示。“我的 → 重置本地演示数据”可重新开始。

演示数据仅保存于本机微信开发者工具 / 当前小程序的本地存储中，不能在两台手机之间同步。

## AA 规则

仅支持同一共同接送区间，不做分段计费：

```text
共同费用（分）= 四舍五入(实际公里 × 发布时约定的每公里成本分值) + 实际过路费（分）
参与人数 = 自家乘员人数（包含驾驶人） + 完成交接的搭乘学生人数
每位搭乘学生费用 = 向下取整(共同费用 / 参与人数)
自家家庭承担费用 = 共同费用 - 所有搭乘学生费用之和
```

尾差由开车家庭承担。每公里成本包含油费，过路费单列；不另加停车、临时绕路费用。所有收费账单都需要搭乘家长确认。记录“结清”表示双方自行确认，平台没有验证实际付款，也不会扣款。

## 开发和验证

Node.js 22 或以上（本机使用 Node.js 24）；业务测试没有第三方依赖。

```powershell
npm.cmd run sync:cloud
npm.cmd test
node scripts/check.js --skip-native
powershell -ExecutionPolicy Bypass -File scripts/native-check.ps1
```

`npm run check` 会在找到微信原生编译器时一起编译 WXML/WXSS。沙箱限制 Node 子进程时，使用上面的 `--skip-native` 与 PowerShell 独立编译组合。可通过 `WECHAT_COMPILER_DIR` 设置其他开发者工具安装目录。

可选真实模拟器冒烟：先 `npm.cmd ci --ignore-scripts` 安装开发依赖，再在开发者工具开启本项目自动化端口：

```powershell
& 'C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat' auto --project $PWD.Path --auto-port 9420 --trust-project
node scripts/smoke.js
node scripts/demo-e2e.js
```

截图写入 `artifacts/`，该目录不纳入版本控制。冒烟脚本只切换页面、读页面状态和截图，不发送搭乘申请。`demo-e2e.js` 检查当前必须为演示模式，再运行完整接送与 AA 结算测试；结束时恢复原本的本地演示数据。

本次开发验证结果见 [测试与验收记录](docs/TESTING.md)。

## 接入真实云环境

见 [云端部署说明](docs/DEPLOYMENT.md)。需要你的小程序 AppID 和云环境 ID。不要把 AppSecret、登录凭证写进仓库或聊天。

当前未实现手机号归属验证、同校与车辆审核后台、微信订阅通知、地图路线距离核验及在线支付。页面状态在进入页面时刷新，**不能当作已送达对方的消息通知**。涉及临时取消、找不到学生等情况，需要主动电话联系。

这版适合本地体验和云端联调。面向真实家长开放前，需要完成审核、通知与隐私流程，以及双手机云端测试，详见 [范围与后续开发](docs/SCOPE.md)。
